## 🔧 Customization Options

You can easily customize:

### Change Colors:
Edit `welcome.css` to change:
```css

.hero-version { background: #9acd32; } /* Version badge */
.btn-demo { background: #f6c544; } /* Demo button */
```

- Main heading

- Button links

### Add Your Logo:
Place your logo in `src/main/resources/static/images/logo.png` and it will automatically display in the navigation.
