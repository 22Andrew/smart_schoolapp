Getting started

  1. Go to Login and choose Admin Login for staff or User Login for student/parent.
  2. After login you land on a dashboard. The left sidebar is the map of the application.
  3. Set the current session from the header if the school year shown is wrong.
  4. Confirm Academics → Class and Section already contain the classes you will use. Admission Enquiry and Student Details read that class table.

Demo logins

The login page includes shortcut buttons that fill a demo account. Use those buttons rather than guessing passwords. Typical staff usernames are:

  • superadmin@gmail.com — entire application
  • admin@gmail.com — school administration
  • teacher@gmail.com — teaching menus only
  • accountant@gmail.com — fees and finance
  • receptionist@gmail.com — front office
  • librarian@gmail.com — library
  • std1 / parent1 — student and parent portals (User Login)

Common tasks

Admit a student

Front Office → Admission Enquiry, then Student Information → Student Admission. Pick Class from the class table, complete required fields, and save.

Find a student

Student Information → Student Details. Choose Class (required), optional Section, then Search. Or search by name, admission number or roll number.

Collect fees

Fees Collection → Collect Fees. Search the student, open Collect Fees, enter payment against the fee master rows.

Mark attendance

Attendance → Student Attendance. Filter class and section, mark Present / Absent / Late / Half Day, then save.

Plan a lesson

Lesson Plan → Manage Lesson Plan. Filter class, section, subject group and subject. Use the calendar view/edit icons. Syllabus Status uses the same filter.

Send a message

Use Communicate for notices, email or SMS. Use the header Chat icon for private threads. Unread badges appear only for the logged-in user.

Roles and menus

Menus are role-based. If you cannot see a screen, you are logged in as a role that does not include it. Super Admin can open everything, including CBSE Setting. Teachers see teaching menus and a read-only Class Teacher list. Accountants see finance. Receptionists see Front Office. Librarians see Library.

Frequently asked questions

The Class dropdown is empty.

Add classes under Academics → Class. Admission Enquiry and Student Details load names from that table.

The dashboard looks empty after login.

Confirm you are Super Admin or Admin for the full dashboard. Hard-refresh the page. If the site was just deployed, wait for the server rebuild to finish.

A teacher cannot edit a form.

Several screens are list-only for teachers (for example Class Teacher assignment and some exam settings). Log in as Super Admin or Admin to change them.

Chat shows other people’s conversations.

It should not. Each user only sees threads they own. If you still see extra contacts, log out and in again so the latest chat privacy rules load.

I forgot a password.

Use Forgot Password on the login page, or ask Super Admin to reset the staff record. Demo accounts can be filled from the shortcut buttons on Login.
