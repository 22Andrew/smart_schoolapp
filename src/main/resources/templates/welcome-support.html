Before you contact us

  • Read the matching topic on Help & Documentation
  • Note the menu path (for example Front Office → Admission Enquiry)
  • Note the login role (Super Admin, Teacher, Student, and so on)
  • Note the class, section and session you were using

In-app help after login

  • Header Chat for a private message to staff who can assist
  • Notice Board for school-wide announcements
  • WhatsApp icon in the header when the school has configured it

What to send

  • What you clicked, what you expected, and what happened
  • A screenshot of the screen (not passwords)
  • Approximate time of the problem
